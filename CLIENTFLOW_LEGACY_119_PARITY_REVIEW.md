# ClientFlow V2 operational parity review against legacy 1.1.19

Status: **blocking source review for the next release after immutable 1.3.17/1218**.

Canonical V2 baseline reviewed: `d405d6be168b6f69dcba772614da6c06434eb8bf`.
Functional acceptance reference: legacy ClientFlow 1.1.19 / sequence 1119. Legacy is a functional reference only; V2 release authority, enrollment binding, unique domain credentials, separate system/update identities and isolated domain architecture remain authoritative.

No finding below authorizes changing immutable release 1.3.17/1218. Any byte change requires a new source/build/release identity.

## Frozen domains

Livestream, Terminal and Remote Desktop remain frozen. The remediation below must not change their protocol, credential, agent, broker, capture or runtime behaviour. Shared Display/Status/System code may only change where a finding explicitly names it. Frozen-domain regression is read-only unless a concrete defect is separately documented.

## Implementation ordering

The change batch must preserve the trust boundary in this order:

1. host bootstrap before consuming claim;
2. exact enrollment/release binding and unique credentials unchanged;
3. post-claim human-account materialization;
4. pending remains runtime-inactive and updater-inactive;
5. approved first activation remains fail-closed;
6. successful activation finalizes install-state and schedules temporary bootstrap-user removal for the next controlled boot;
7. desktop/session baseline is applied without optional lockdown;
8. optional lockdown is a separate Display command/broker with rollback;
9. reboot/reconnect proves two-user state, GUI/session policy and runtime;
10. normal updater and pre-first-activation repair remain distinct, explicit paths using the one canonical catalog/artifact authority.

## Release gate

No catalog promotion or new physical clean install until the new source identity passes compile/tests, executable integration gates, reproducible build, manual approval, immutable publication to the canonical Render store and separate catalog promotion. 1.3.17/1218 remains immutable historical evidence.
